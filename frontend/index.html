How to read the table

Rolling 1Y is every 1-year holding period in the fund's history: the median is what a typical year gave, the worst is what an unlucky entry gave. A single "1Y return" depends on which day you looked; the rolling range doesn't. vs NIFTYBEES is the fund's 1Y return minus the index ETF's — the fee-free alternative it has to beat.

More

Best-effort tools quarantined from the core app: manual or fragile data sources live here so their failures never touch your watchlist, portfolio, or signals.

Data doctor

Finds symbols with missing or thin history and repairs them in one batch — re-downloading and switching a listing to its sister exchange (.BO ↔ .NS) when that side has the real data.

Shareholding pattern

No free API serves this reliably, so it's manual by design: after each quarter's filing, copy four numbers from Screener.in or the exchange — the trend chart and warnings (promoter drops, rising pledges) are then automatic.

Read about a stock

Honest version of a news feed: always-current links instead of a stale scraper.

Options sentiment

PCR and max pain from NSE's option chain — F&O stocks and indices only. NSE's endpoints are moody; failures say so plainly rather than showing stale numbers. Sentiment context, not a signal.
